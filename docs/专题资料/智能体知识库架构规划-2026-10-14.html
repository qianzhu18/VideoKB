故障时 Agent / 用户应做什么

这些是拟补齐的恢复契约，不是可执行控制台。检索、生成、上传与入库分别管理预算。

12 个场景
层次故障动作边界
接入端点有响应，token不正确停止自动重试分层诊断；修正凭据，不扩大主体权限
接入上游会话过期单次刷新现有40100重登录一次；补并发刷新合并
调用429 / 临时5xx / 网络抖动有限只读重试建议最多2次额外尝试，退避抖动且不超过总deadline
调用ask超时 / 响应丢失结果未知可能已调用模型；先有请求幂等/状态，再允许重新生成
调用READY零命中同范围补查限预算拆题改写；不能断言整套资料没有该内容
调用全部召回通道失败返回不可用不能伪装为空知识或证据不足
视频上传断网 / 浏览器重开保留凭据续传已有最多4次分片尝试；补服务重启与响应丢失实测
视频MQ停机 / worker退出由持久job恢复已有三次尝试/心跳；补实机恢复与旧epoch发布隔离
视频ASR最后阶段失败恢复失败阶段整体context已可复用；部分ASR失败可返回余结果，需覆盖率和子片段恢复
视频新文件 / 索引更新失败旧版保留索引重建已保护旧READY；目录CHANGED删旧路径必须修
证据超过50行 / 字段裁剪显示不完整拟增分页/hasMore/truncated；引用绑定原文版本和时间
证据目录撤权 / 删除立即核权每次重新验证，不以Agent历史缓存作为继续访问依据

# 原文、检索块与向量复用

状态：`active`
最后复核：2026-10-09

对应 BR-04、BR-06、BR-08 和 `feat/evidence-chunking`。原文属于证据契约，检索块属于派生索引；后续 BM25、重排、回答、更新分支复用此契约。

## 当前实现

V11 保留 `knowledge_segments` 原始 ASR/OCR 时间窗，新增 `knowledge_retrieval_blocks`、`knowledge_block_evidence` 和 `knowledge_embedding_cache`。source generation 保存 index_profile、模型和实际维度；块映射保存原文 ID 和顺序。只有原文/块/向量全部成功才原子发布，失败不改变已有 READY 指针。旧原文与索引不覆盖。

默认 profile 为 `raw-boundary-v1-max1400-overlap1`：直接读取原始上下文，不调用五分钟摘要生成。按原始窗拼接、句子标点、显式转场和相邻文本 bigram 相似度分界，最多 1400 Unicode codepoints、3 个原始窗；容量边界可重叠 1 窗，主题切换或超过 15 秒的间隔不跨界。相似度阈值 0.06。超长原始窗按句子/长度切文本块，所有子块仍映射该原始窗，不能虚构句子级精确时间。它是确定性边界启发式，不是已验证的 LLM 语义分块。

原文不附重复的五分钟摘要。向量输入为块内原始 ASR/OCR，cache key 使用 owner、模型、profile、文本 SHA256；同内容重复分块和重建复用向量，不同主体、模型/profile 不能共用。空/非有限向量和维度不一致取消发布。新 generation 仍写新的 Qdrant 点，缓存复用不等于跳过版本发布。

`knowledge.index.profile=legacy-v1` 保留原算法作为新 generation 的对照入口；切换需要显式重建，已有版本不会自动转换。模型提供方实际发生变化时须更新模型/profile 标识；同名模型的静默服务端变更无法仅由缓存 key 自动识别。

## 对外证据

检索命中增加 versionId、indexProfile、evidence 数组。新索引 segmentId 是检索块 ID；evidence 中 segmentId 才是原文 ID，保留 source/version/media/time/ASR/OCR。旧索引命中同样映射一个原始窗。生成模型只收到原文 ID/文本，返回引用使用原文 ID、versionId 和原始时间；摘要不能通过原文校验。此处尚没有完成结论语义校验，文字匹配不能证明答案正确。

`GET /knowledge/sources/media/{mediaId}/segments?versionId=...` 可读取该 owner 的已保留 READY 原文版本，省略使用当前版本；越权、删除或未发布版本不能读取。MCP `get_video_evidence` 可传 versionId，返回原文 ID/版本。Web“原文片段”可展开各个原始窗并点击回看。历史资产替换/清理和会话持久引用由后续分支完成。

## 验收证据

- 后端 198、MCP 17、前端 26、离线指标 7 项测试通过，前端生产构建通过。新增测试覆盖主题/间隔、重叠、Unicode 长窗、缓存主体/模型/profile 隔离、非法向量和原文引用。
- [生命周期实机回归](../../eval/reports/evidence-block-smoke-20261008.json)：10 项通过。V10→V11 在隔离 MySQL 成功；原文时间/文字保持、旧版可读、块到原文映射、向量服务不可用时缓存复用、新内容失败保留 READY、失败版本过滤、MCP 历史原文版本。
- [真实重建映射](../../eval/reports/evidence-block-map-20261008.json)：13 门真实课程、674 原始窗 → 592 块，真实 BGE-M3 1024 维；旧原文仍可读。没有重跑 ASR/OCR、没有生成摘要。
- [开发集对照](../../eval/reports/evidence-block-dev-20261008.json)：必要证据 Recall@8 dense 94.7%、LIKE 15.8%、RRF 78.9%。dense 的关键跨视频开发题找全；混合仍未找全，尚未满足完整检索验收。旧算法基线见 [固定基准](真实证据基准-2026-10-08.md)。保留集此次不运行，不据其调策略。

小语料顺序测试包含查询缓存冷热差异，不是公平吞吐实验。当前报告使用 nearest-rank P95；首轮基线采用 floor 排位，小样本尾延迟口径不同，不做速度提升结论。实际模型账单未知，费用 null，不把配置价格零认定为免费。质量报告的工作区源码 hash 和 dirty 标识用于解释测试代码边界。

## 遗留与兼容

LIKE 临时兼容路径读取当前块并排序，还不是可扩展的 BM25；后续词法分支替换主路径。查询接口保留旧字段，但引用方应使用 evidence 原文 ID/version，不能把块时间当句子时间。历史原文暂不清理，后续清理必须保证有效引用和活动版本。版本切换查询快照继续可读，目录/owner 撤销仍重新过滤。生产升级/回退见 [兼容说明](../兼容与发布说明.md)，迁移理由和阶段记录见[向量数据库迁移决策与过程记录](向量数据库迁移决策与过程记录.md)。

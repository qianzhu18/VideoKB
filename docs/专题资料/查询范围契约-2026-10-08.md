# 查询范围契约验收

状态：`active`
最后复核：2026-10-08

对应 BR-07 与 `feat/query-scope-contract`，使用基线和已合入的真实证据基准，不引入新的社区权限。

## 行为

网页显式传当前空间与可选目录；目录包含子目录。HTTP 与独立 MCP 调用省略空间时，由后端 `KnowledgeScopeResolver` 解析为用户默认空间。目录必须同传空间，客户端不能用 owner 参数决定权限。MCP 不再自行扇出十个空间，避免 search 与 ask 使用不同范围。

`/knowledge/search/details` 新增 `{scope,hits,warnings}`，旧 `/knowledge/search` 保留数组。MCP 检索使用新契约。scope 区分 READY、PARTIAL、NOT_READY、FAILED、EMPTY，只统计授权范围内的资料；准备状态不是检索相关性。PARTIAL 使用已发布版本并提示未就绪资料；没有 READY 来源时 ask/stream 不调用生成模型，未就绪与失败返回 NOT_READY，空范围返回不足证据。问答附相同 scope，MCP 保留状态和警告。

Vue 切换空间/目录会清空结果、取消旧问答并丢弃旧检索的晚到响应。会话绑定范围属于后续会话分支，本分支没有实现多轮。

## 证据

- 后端测试 192 项通过（其中范围与未就绪新增 5 项）；MCP 14 项通过（新增真实 HTTP 客户端测试）；Vue 26 项及构建通过。
- [真实基础设施范围回归](../../eval/reports/query-scope-smoke-20261008.json)：13 项通过，同主体 Web/MCP 默认/显式范围、目录准备状态、空范围不扇出、移除引用和不同 owner 拒绝。MySQL/Redis/MQ/Qdrant/HTTP 真实，AI 为确定性替身；没有真实模型问答质量结论。
- [页面截图](../../eval/reports/query-scope-ui-20261008.png)：当前空空间仅搜证据显示“当前范围没有资料，请导入资料或切换知识范围”，没有误用另一个空间的课程。
- 已有检索测试继续覆盖召回期间移除目录的过滤，以及发布切换时查询版本快照可读。这一版本快照不等于历史引用读取契约，后续证据分支负责统一原文版本接口。

## 兼容与边界

无数据库迁移。MCP 的返回结构及默认范围变化需要更新外部客户端，具体见 [兼容说明](../兼容与发布说明.md) 与 [MCP SOP](../外部助手接入指南.md)。MCP 所有客户端依然使用一个上游账号，多客户端令牌不等于社区主体隔离。接口空候选仍可能来自召回失败，通道降级可见性在检索分支补齐；scope READY 不证明向量服务正常或答案正确。

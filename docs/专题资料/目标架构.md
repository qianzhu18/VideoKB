## 目标与现行边界

业务目标是组织视频资料、动态安全更新、跨视频回答、连续追问与外部学习助手接入。第一批已建立内容/归属、独立任务、generation 与授权查询的基础结构；下一步应补齐完整生命周期和有据可测的使用效果。

| 层 | 当前基础 | 完整目标 |
| --- | --- | --- |
| 内容与归属 | source、media、placement，多目录复用 | 稳定内容身份下的资产版本替换；课程/章节关系按实际需求决定 |
| 入库与恢复 | 持久 job/outbox、MQ、共享提取与 Checkpoint | 分片状态/缺口/覆盖率、长任务恢复、容量和成本控制 |
| 索引 | generation 发布，旧版保留 | index profile 全面版本化、对账、旧版清理、可替换写入层 |
| 检索 | 默认 Qdrant dense + LIKE + RRF，可显式启用 Milvus BM25 | 已有词法对照；补 reranker/覆盖、Milvus dense 对照与完整迁移 |
| 证据与回答 | 单轮回答、引用文本检查 | 原始证据/派生块分离、claim 对照、指定版本/时间、部分回答 |
| 对话 | 单次 ask | conversation 与 scope、指代改写、每轮检索与撤权处理 |
| 开放 | 五工具与单上游主体 | 稳定范围契约；多人开放前主体、空间权限、配额和审计绑定 |
| 评测 | 历史小真实集、当前结构/合成负载 | 真实学生任务、严格证据指标、混合容量/恢复/成本报告 |

## 数据与任务约束

稳定内容身份管理多个资产版本，目录只引用内容；上传/转写改动先创建待发布版本，不能先销毁旧资料。处理产物携带 parser/chunk/embedding/profile 的版本与原始时间轴映射。长课程可分片任务、持久失败单元与覆盖率，具体粒度由真实语料与成本验证。

MySQL 是内容、任务、授权、原始证据和当前索引指针的真源；向量库是可重建索引。新版本全部写完并验证后发布，旧版本按保留策略清理；清理需避开活动查询/引用，删除与撤权优先阻止检索。没有真实恢复验证，不承诺任意长视频支持。

报告、章节总结和测验可使用内容产物，独立决定重试与预算，不能改变知识 READY 的事实。

## 检索对照与库迁移门禁

先建立原始片段级 query/gold 标注，固定语料、切块、embedding、scope 与参数，分别比较 dense、词法、RRF、reranker 的增益，覆盖精确术语、中英混杂、跨视频综合与 OCR。负责人于 2026-10-09 指定 Milvus 为后续优先技术栈。优先验证 Milvus dense + 原生 BM25 的承载方案；当前 Qdrant 数据通过双写、回灌、影子查询、授权/版本对账和回退验收后再切流。库选择与检索策略的收益分别记录。

写入侧先抽象、双写并对账，再回灌与影子查询。比较必要来源/片段覆盖、引用支撑、拒答、P95、吞吐、资源及成本。阈值依据实际业务容量确定；未确定的数字进入决策/研究，不伪造通过门禁。

## 对话、证据与开放契约

每轮对话绑定主体与显式 scope；指代消解只帮助检索，历史回答不能作为新事实。资料撤权或版本变化后重新验证原始引用。自然语言答案需要 claim 对指定证据的关系，证据不足允许部分回答并说明缺口。

Web 和 MCP 共享范围解析与检索服务；未指定空间的 search/ask 必须最终统一明确含义。目录发现和未就绪信息是协议能力，不能用“空结果”表达任务还未完成。多人开放前需客户端绑定主体、允许空间、scope、配额与审计；不沿用共享上游账号作为社区权限实现。

## 业务验证与执行

收集真实学生的复习问题、正确片段、时间成本和使用结果，构成跨视频完整来源/片段标注。合成测试负责覆盖故障与边界，真实研究负责验证需求和价值，两者分别保存。

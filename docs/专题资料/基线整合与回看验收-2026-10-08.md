## 实际发现与修正

- 上传后 Vue 的自动报告调用仍会触发 Agent，已移除；独立知识任务自动创建，报告主动开启。
- 仅搜证据的时间此前是不可点击文本，已加回看按钮并验证跳转。
- 上传 XHR 的旧 401 响应可能清除新登录，加入与普通请求相同的会话校验；分片续传按用户隔离。
- 不能用“还没有台账”判断活跃标记过期，这会误清并发提交；保留原子受理标记直到任务终止/TTL。
- 独立 MySQL 使用 UTC，投递失败后 Java 本地时间写入造成约八小时延迟；重试时间改用数据库 CURRENT_TIMESTAMP/TIMESTAMPADD。此次 UTC 基建回归验证任务可完成。
- fixture MQ 的新持久卷权限导致 broker 无法启动，增加可重复的卷初始化服务。
- 文档 CI 忽略代码块内的演示链接，仍校验真实导航链接。

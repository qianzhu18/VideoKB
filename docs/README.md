## 当前范围

当前主线是“证据约束的长视频理解 Agent”：视频经 ASR/OCR 形成时序证据，按目标混合检索，受控 Agent 工作流生成可回溯结论；系统还覆盖断点恢复、幂等、预算、降级、评测和观测。

下一项产品增量是 **Collection（学习资料分区）**：用户可建立如“Python 学习”“Java 学习”的空间，并把多个本地视频放入其中。完成后可在 Collection 内检索并返回“视频标题 + 时间戳 + 原文证据”。这是后续实现，不应写成既有能力。

本阶段不实现公网商业化、支付、多租户企业权限、未授权平台抓取、全量网页/PDF 接入或为了名词而加的 Multi-Agent。它们可作为设计方向，不能冒充已完成事实。

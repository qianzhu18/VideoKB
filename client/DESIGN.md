# VideoKB 界面设计系统

状态：`active`  
最后复核：2026-10-18

## 产品气质

VideoKB 是一款整理个人视频资料、搜索讲解出处并回到原片的效率工具。界面像一册可检索的工作笔记：克制、清楚、让证据和下一步操作容易找到。避免套用常见 AI 产品的发光渐变、抽象旋涡、虚构数据面板和同构卡片墙。

## 视觉主题与 token

主题名：**Cobalt Field Notes**。品牌仍使用钴蓝，但它只标记主要操作、当前选择和链接；时间戳使用低饱和琥珀色，状态色只表示真实状态。白纸底、细分隔线、较少阴影构成页面层次。

唯一 token 源为 `client/src/tokens.css`。页面 CSS 使用命名颜色、字体、间距、圆角和阴影变量；避免新增裸色值或页面自定义色。颜色基于 OKLCH，核心角色如下：

| Token | 用途 |
| --- | --- |
| `--color-paper` / `--color-white` / `--color-paper-raised` | 页面、内容面、轻微分组 |
| `--color-ink` / `--color-muted` / `--color-subtle` | 主次文字与辅助信息 |
| `--color-rule` | 边界和内容分隔 |
| `--color-cobalt` / `--color-cobalt-wash` | 操作、链接、当前选择 |
| `--color-amber` | 视频时间戳与少量序号 |
| `--color-red` / `--color-green` | 真实错误与成功状态 |

`--space-1` 到 `--space-9` 是共享间距阶梯。正文字体使用系统字体；营销标题使用本机宋体衬线字体；时间戳、数量和编号使用等宽字体。不加载外部字体。

## 页面结构

- **产品首页：Long Document。** 左对齐价值主张和操作，旁边展示明确标注为虚构的“问题—回答—原片出处”示例；随后说明导入、检索、回看路径，最后列出任务、Agent 当前能力和 FAQ。
- **我的视频：Workbench。** 顶部说明导入用途；提供本地文件、公开视频链接和批量导入；直接呈现上传状态与资料列表。处理状态可见，但不重复展示流程导航卡片。
- **知识空间：Workbench。** 空间与目录、检索与来源并列；回答和证据分层，时间戳是回看片段的明确入口。Agent 连接配置仍按当前交互呈现。

页面共用相同的导航、文字层级、表单、边框与状态颜色。小屏下分栏改为纵向，导航允许换行或收纳；320、375、414、768px 视口不得出现横向页面滚动或换行的点击标签。

## 交互与文案

- 保留现有导入、空间整理、搜索、问答、引用跳转和 Agent 连接行为；视觉调整不改变 API 或权限边界。
- 提示具体写明资料状态和用户能做的下一步。避免“智能赋能”“一站式 AI 助手”等空泛表述。
- 首页示例必须标注为示例；不得展示虚构规模、成功率、节省时长或实时服务状态。
- 上传完成、知识可检索、单视频报告完成是不同状态。Agent 仅承诺当前 MCP 只读检索能力，多个客户端令牌仍使用同一配置账号。
- 保留键盘焦点样式和 `prefers-reduced-motion` 支持；不使用滚动劫持、大幅布局动画或无语义装饰动画。
